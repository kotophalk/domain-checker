# Domain Checker

Микросервис на Python для быстрой и надежной проверки доступности доменных имен, включая национальные зоны (например, `.ru`, `.рф`, `.su`) и популярные международные домены (`.com`, `.net`, `.info` и др.).

## Особенности
* **Максимально легковесный**: Написан с использованием встроенного `http.server` из стандартной библиотеки Python. Без использования тяжелых фреймворков (Django/Flask/FastAPI).
* **Минимум зависимостей**: Единственная внешняя зависимость — библиотека `python-whois`, которая берет на себя всю работу по корректному запросу к серверам регистраторов и парсингу ответов.
* **Асинхронный веб-интерфейс**: Простой и стильный фронтенд (написан на ванильном JavaScript и CSS) позволяет массово проверять домены списками. Страница не перезагружается, результаты подгружаются динамически.
* **Обработка ошибок**: Если сервер Whois недоступен или введена несуществующая зона, скрипт не падает и не выдает ложное «Занят», а корректно отображает статус ошибки.

## Установка и запуск

1. Склонируйте репозиторий:
   ```bash
   git clone git@github.com:kotophalk/domain-checker.git
   cd domain-checker
   ```

2. Установите зависимость `python-whois`. В зависимости от системы:
   * На Ubuntu/Debian:
     ```bash
     sudo apt-get install -y python3-whois
     ```
   * Через pip:
     ```bash
     pip install python-whois
     ```

3. Запустите сервер:
   ```bash
   python3 app.py
   ```
   *По умолчанию сервер запускается на порту `8080`. Для фонового запуска можно использовать `nohup python3 app.py > app.log 2>&1 &`.*

4. Откройте в браузере:
   `http://localhost:8080` (или `http://<ваш_IP>:8080`)

## Структура проекта
* `app.py` — бэкенд на Python (API для проверки доменов `/api/check` и раздача статики).
* `static/index.html` — минималистичный фронтенд с формой массового ввода доменов.
